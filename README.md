# Excel Formula Practice – Sample Superstore

## 📌 Overview
This task focuses on practising essential Excel formulas used in data analysis with the Sample Superstore dataset. It demonstrates how Excel functions help analyze sales data and perform calculations efficiently.

## 🎯 Objectives
- Practise commonly used Excel formulas.
- Perform conditional calculations and lookups.
- Understand logical and text functions.
- Improve spreadsheet analysis skills for Data Analyst roles.

## 🛠️ Tools Used
- Microsoft Excel
- Google Sheets
- Sample Superstore Dataset

## 📊 Excel Functions Covered
- `SUM`
- `AVERAGE`
- `SUMIF`
- `SUMIFS`
- `COUNTIF`
- `XLOOKUP`
- `INDEX/MATCH`
- `IF`
- Nested `IF`
- `IFERROR`
- `LEFT`
- `RIGHT`
- `CONCAT`

## 📁 Workbook Contents
- **Read Me:** Instructions for using the workbook.
- **Raw Data:** Sample Superstore dataset.
- **Formula Practice:** Examples of Excel formulas with editable input cells.
- **Formula Notes:** Explanation of each function, its purpose, and usage.

## 🚀 How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the Formula Practice worksheet.
4. Change the yellow input cells to test different values.
5. Observe the formula results and refer to Formula Notes for explanations.

## 📌 Key Learning Outcomes
- Performing conditional calculations.
- Looking up and retrieving data.
- Applying logical conditions.
- Handling formula errors.
- Extracting and combining text values.
